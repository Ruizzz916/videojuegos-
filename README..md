Proyecto: Calculadora Básica

Descripción
Este proyecto es una calculadora sencilla que permite sumar y restar dos números usando Python.

Funcionalidades
Suma de dos números
Resta de dos números

Uso de módulos del IDE
Editor de código: escritura del programa
Terminal: ejecución del código
Depurador: revisión de errores
Explorador: organización de archivos
Cómo ejecutar
Ejecutar en terminal:
python calculadora.py
